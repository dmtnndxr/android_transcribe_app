# План развития Offline Voice Input+

Состояние на 1 октября 2026, версия 0.1.21.

Распространение: **только GitHub Releases**. Платные площадки и площадки с ручной
проверкой (Google Play, Samsung Galaxy Store, основной F-Droid) пока не
рассматриваем. Бесплатно и без проверки добавить можно только ссылку для
Obtainium в README (этап 3).

Этапы идут в рекомендуемом порядке. Скриншоты и ролики стоит снимать **после**
этапов 1 и 2: история и уведомления меняют интерфейс, иначе их придётся
переснимать.

## Этап 1. Текст не теряется — сделано

**Проблема.** Долгая диктовка распознаётся заметное время. Если за это время
свернуть приложение или перейти в другое поле, вставлять текст некуда. Раньше
клавиатура держала его в памяти и вставляла в первое открывшееся поле — это
могло быть чужое поле, а при выгрузке клавиатуры текст пропадал.

**Как работает теперь.**
- [x] Текст вставляется сразу, только если открыто то же поле, где начинали
      запись (приложение + id поля из `EditorInfo`).
- [x] Иначе текст копируется в буфер обмена с всплывающим сообщением
      «Транскрипция скопирована в буфер обмена». Содержимое буфера помечено
      как конфиденциальное (`EXTRA_IS_SENSITIVE`), система не показывает его
      в превью.
- [x] Настройка «Копировать в буфер, если некуда вставить» (по умолчанию
      включена). Если выключена, при следующем открытии клавиатуры появляется
      плашка «Не вставлено: …» с кнопками «Вставить» и «Скрыть».
- [x] Если в течение минуты вернуться в то же поле, текст вставляется сам
      (веб-поля Firefox/Gemini иногда сами теряют фокус).
- [x] Результат правки голосом, если выделение успело измениться, тоже
      уходит в буфер, а не пропадает.
- [x] Микрофон другой клавиатуры (`VoiceRecognitionService`): если
      приложение, которое просило распознавание, уже закрыто, текст уходит
      в буфер.
- [x] Уведомления решили не делать: лишнее разрешение и лишний шаг на
      онбординге.

**Заодно.**
- [x] «Отменить» после обычной диктовки убрано, осталось только после правки
      голосом (она заменяет исходный текст).
- [x] Палочка правки: три состояния (контур + «Выделите текст» / заполненная
      «Изменить» / яркая «Стоп») вместо полупрозрачности; круглый эффект
      нажатия у палочки и кнопки «Диктовка с ИИ».

**Осталось.**
- [ ] Если клавиатура-клиент (Gboard) сама отменяет распознавание при
      сворачивании, запись выбрасывается в Rust-ядре. Решить, нужно ли
      дораспознавать её в этом случае.
- [ ] Текст, ожидающий вставки, живёт только в памяти клавиатуры. Закроется
      историей (этап 2).
- [ ] «Tap to Record» дублируется в строке статуса и под кнопкой.

## Этап 2. История транскрипций — основа сделана

**Что хранится** (только на устройстве, в SQLite `history.db` и
`filesDir/history/*.wav`): запись, распознанный текст, итоговый текст (после
ИИ или правки), для правки — выделенный текст «было» и команда, источник
(диктовка / с ИИ / правка / другая клавиатура), длительность, куда ушёл текст
(вставлен / в буфере / не вставлен / без изменений / ошибка / отменено) и
причина ошибки.

**Сделано.**
- [x] Карточка «История» на главном экране и экран истории: список с датой,
      источником, длительностью и пометкой, если текст ушёл не в поле.
- [x] Раскрытая запись: полный текст с выделением кусочков, «Распознано»,
      «Было», «Команда», причина ошибки; кнопки-иконки ▶/■, копировать,
      поделиться, удалить.
- [x] Поиск по тексту.
- [x] Настройки (⚙): сохранять историю, сохранять записи, срок хранения
      записей (всегда / 1 / 7 / 30 дней, по умолчанию всегда), занятое место;
      «Очистить историю» в меню.
- [x] Rust-ядро сохраняет WAV при остановке записи (около 2 МБ на минуту).
- [x] Записи во внутренней памяти приложения: плееры и галерея их не видят.
      История исключена из облачных копий и переноса на новый телефон.

**Осталось.**
- [ ] **Распознать заново** другой моделью и **обработать заново** через ИИ.
- [ ] Записи для микрофона другой клавиатуры (`VoiceRecognitionService`):
      сейчас сохраняется только текст.
- [ ] Сжатие записей (Opus/AAC — примерно в 10 раз меньше WAV).
- [ ] Название модели распознавания в записи.
- [ ] Плашка «Не вставлено» и автовставка живут только в памяти клавиатуры;
      можно показывать последнюю невставленную запись из истории.
